ASR MODEL

Automatic Speech Recognition for 9 Indian Languages

About This Model

Automatic Speech Recognition ESPnet respin 9 languages speech audio indian-languages License: CC-BY-4.0

This ASR system is built on the E-Branchformer architecture using the ESPnet2 toolkit, and trained on the RESPIN-S1.0 corpus — a large-scale, multi-dialectal, multi-domain read-speech dataset developed at SPIRE Lab, IISc. It supports transcription across nine major Indian languages, including several regional dialects that are underrepresented in most existing speech datasets. The repository contains E-Branchformer-based ESPnet2 ASR models trained on the RESPIN-S1.0 small train splits.

Training Corpus

RESPIN-S1.0 — 10,000+ hours of validated read speech, spanning 38+ dialects across 9 Indian languages, collected across agriculture and finance domains.

Architecture

E-Branchformer encoder-decoder, trained using the ESPnet2 framework. Benchmarked against TDNN-HMM, Whisper, and wav2vec2-based baselines.

Installation & Download

Follow the steps below to download and run this model locally using ESPnet2. Make sure you have completed the ESPnet installation first.

1. Install ESPnet and download the model

cd espnet
pip install -e .
cd egs2/respin_small/asr1
./run.sh --skip_data_prep true --skip_train true --download_model SpireLab/spire_respin_baselines_espnet

2. Use the model in Python (ESPnet2)

from espnet2.bin.asr_inference import Speech2Text

model = Speech2Text.from_pretrained(
    "SpireLab/spire_respin_baselines_espnet"
)

speech, rate = soundfile.read("speech.wav")
text, *_ = model(speech)[0]

Research Paper

This model is trained on the RESPIN-S1.0 corpus, introduced in the following peer-reviewed publication.

RESPIN-S1.0: A read speech corpus of 10,000+ hours in dialects of nine Indian Languages

NeurIPS 2025 — Datasets & Benchmarks Track

Saurabh Kumar, Abhayjeet Singh, Deekshitha G, Amartyaveer, Jesuraj Bandekar, Savitha Murthy, Sumit Sharma, Sandhya Badiger, Sathvik Udupa, Amala Nagireddi, Srinivasa Raghavan K M, Rohan Saxena, Jai Nanavati, et al. — IISc Bangalore & Navana Tech

RESPIN-S1.0 is the largest publicly available dialect-rich read-speech corpus for Indian languages, comprising more than 10,000 hours of validated audio across nine languages — Bengali, Bhojpuri, Chhattisgarhi, Hindi, Kannada, Magahi, Maithili, Marathi, and Telugu — spanning 38+ dialects and two domains (agriculture and finance). The paper benchmarks several ASR architectures, including the E-Branchformer model used on this page, and shows that fine-tuning on RESPIN significantly improves recognition accuracy over pretrained baselines.
